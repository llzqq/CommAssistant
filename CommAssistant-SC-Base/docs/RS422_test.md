# RS422 测试步骤

目标：让小白也能完成最小闭环测试，确认 RS422 连接后可以正常收发 `HELLO` / `ACK`。

## 1. 准备

- 两端都启动 `Comm Assistant`
- 两端都选择 `RS422` 模式
- 准备两路 RS422 设备，或一端是真实设备，另一端是串口转 RS422 转接设备

## 2. 填参数

两端都设置相同的串口参数。

建议先用：

- 波特率：`115200`
- 数据位：`8`
- 校验位：`None`
- 停止位：`1`

## 3. 点 Apply

- 先在两端分别点 `Apply`
- 成功后，连接状态应显示为已连接

## 4. 点 Start Test

- 先在任意一端点 `Start Test`
- 程序会发送 `HELLO`
- 对端收到后回 `ACK`
- 收到 `ACK` 后显示 `Handshake success`

## 5. 怎么算成功

- 发送端日志能看到 `TX HELLO`
- 接收端日志能看到 `RX HELLO`
- 回包端能看到 `TX ACK`
- 发起端能看到 `RX ACK`
- 界面显示 `Handshake success`

## 6. 收发消息

握手成功后，直接在主界面发送区输入内容并发送。

预期现象：

- 发送端日志出现 `TX ...`
- 接收端日志出现 `RX ...`
- 接收端主界面接收区显示内容

## 7. 常见问题

- 没有任何反应：先检查两端串口参数是否完全一致
- 一直失败：检查 RS422 线序和转接设备是否接对
- 有 `TX` 没有 `RX`: 说明链路没通，优先查硬件和接线
- `Apply` 失败：检查串口号是否正确、设备是否被别的软件占用
