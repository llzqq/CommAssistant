# RS422 测试步骤

目标：让没有接触过 RS422 的人，也能把 Windows 和树莓派的 RS422 硬件接好，并完成 `HELLO` / `ACK` 的最小闭环测试。

## 1. 先认识 RS422

RS422 是差分串行通信。常见信号名有：

- `TX+`
- `TX-`
- `RX+`
- `RX-`
- `GND`

RS422 和 CAN 不一样。RS422 通常需要把发送端接到对端的接收端，也就是 TX/RX 交叉连接。

## 2. 需要哪些硬件

如果你的场景是 `Windows 电脑 <-> 树莓派`，最小硬件组合是：

- Windows 侧 `USB 转 RS422` 适配器 1 个
- 树莓派侧 `USB 转 RS422` 适配器 1 个
- `TX+ / TX- / RX+ / RX-` 接线
- 建议再准备一根 `GND` 线

这里按你的最终方案，不使用 RS422 HAT，也不直接使用树莓派 GPIO 串口。

## 2.1 为什么树莓派也要 USB 转 RS422

树莓派 GPIO 上的普通串口是 TTL 电平，不是 RS422。

所以树莓派要参与 RS422 通讯，必须有一个真正的 RS422 接口。当前方案就是在树莓派上也插一个 `USB 转 RS422` 适配器。

这样两边都是标准 RS422 口：

- Windows 侧：USB 转 RS422
- 树莓派侧：USB 转 RS422

## 3. Windows 连接树莓派时，怎么连

两只 `USB 转 RS422` 适配器之间通常这样接：

- Windows 适配器 `TX+` 接树莓派适配器 `RX+`
- Windows 适配器 `TX-` 接树莓派适配器 `RX-`
- Windows 适配器 `RX+` 接树莓派适配器 `TX+`
- Windows 适配器 `RX-` 接树莓派适配器 `TX-`
- 两边 `GND` 建议相连

如果你把它画成图，大概就是：

```text
Windows USB-RS422  ---- TX+ ---------------- RX+ ----  树莓派 USB-RS422
Windows USB-RS422  ---- TX- ---------------- RX- ----  树莓派 USB-RS422
Windows USB-RS422  ---- RX+ ---------------- TX+ ----  树莓派 USB-RS422
Windows USB-RS422  ---- RX- ---------------- TX- ----  树莓派 USB-RS422
Windows USB-RS422  ---- GND ---------------- GND ----  树莓派 USB-RS422
```

```
1 ------- 3
2 ------- 4
3 ------- 1
4 ------- 2
5 ------- 5
```



注意：

- RS422 通常是 TX 接对端 RX
- 不同适配器可能把 `+/-` 标成 `A/B`
- 如果只看到 `A/B`，先查适配器说明，不要直接猜
- 线先短一点，最容易排查问题

## 4. 软件参数

两端先用同一组串口参数：

- 波特率：`115200`
- 数据位：`8`
- 校验位：`None`
- 停止位：`1`

两端参数必须完全一致。

## 5. 测试步骤

1. Windows 侧插入 `USB 转 RS422`
2. 树莓派侧插入 `USB 转 RS422`
3. 按上面的方式接好 `TX+ / TX- / RX+ / RX- / GND`
4. 两端都启动 `Comm Assistant`
5. 两端都切到 `RS422` 模式
6. 两端选择各自的串口
7. 两端设置相同串口参数
8. 两端分别点 `Apply`
9. 任意一端点 `Start Test`
10. 观察是否收到 `ACK`，并显示 `Handshake success`

## 6. 成功时看什么

- 发起端日志出现 `TX HELLO`
- 对端日志出现 `RX HELLO`
- 对端回包日志出现 `TX ACK`
- 发起端日志出现 `RX ACK`
- 界面状态显示握手成功

## 7. 常见问题

- `Apply` 失败：检查串口号、驱动和设备是否被占用
- 只有发送，没有接收：优先检查 `TX/RX` 是否接反
- 一直收到乱码：检查波特率、数据位、校验位、停止位是否一致
- 线都接对了还是不通：检查 `+/-` 是否接反
- 不稳定：检查 `GND` 是否连接，先用短线验证

## 8. 对新手的建议

先把两只 `USB 转 RS422` 适配器直接连起来做闭环。这个场景变量最少，最容易判断是软件问题还是接线问题。

等双 USB-RS422 测通后，再接真实 RS422 设备。
